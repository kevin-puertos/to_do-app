# Todo API

API REST desarrollada con Spring Boot.

## Tecnologías

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- MapStruct

## Funcionalidades

- Crear tareas
- Listar tareas
- Actualizar tareas
- Eliminar tareas

## Ejecutar

1. Crear base de datos PostgreSQL
2. Configurar application.properties
3. Ejecutar:

./mvnw spring-boot:run
