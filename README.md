# ToDo API

API REST desarrollada con Spring Boot.

## Tecnologías

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- MapStruct
- Maven

## Funcionalidades

- Crear tareas
- Obtener tareas
- Actualizar tareas
- Eliminar tareas

## Próximas mejoras

- JWT Authentication
- Roles y permisos
- Docker
